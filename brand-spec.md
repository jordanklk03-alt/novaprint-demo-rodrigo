## Reglas de uso

Las imágenes se referencian siempre desde sus URL persistentes `/manus-storage/...`; no se copian al árbol del proyecto. El azul de tinta se reserva para acciones, foco, estados activos y guías de personalización. El texto colocado sobre imágenes debe usar una capa de contraste o situarse sobre una zona de baja complejidad visual.
